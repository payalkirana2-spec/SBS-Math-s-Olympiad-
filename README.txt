IMPORTANT — DEMO ONLY / NOT READY FOR A REAL PUBLIC EXAM
This starter uses browser localStorage. Registrations, exam attempts and results are stored only in the browser/device used. They are not shared with the school or other participants. Clearing browser data can erase them. Different students/devices do not share a database.
The question bank, answer keys, demo PIN and exam logic are delivered to the browser and can be inspected or changed by participants. The local timer and one-attempt check can be bypassed. Do not use this starter to collect real student data or conduct a high-stakes public examination.

Before public launch, have a developer connect a secure backend/database and implement:
- secure student registration and authentication;
- server-side exam timing, question delivery, answer storage and marking;
- protected answer keys and admin-only result controls;
- duplicate/attempt controls, backups, privacy notice and parent/guardian consent;
- load and security testing for the expected participant volume.

Free static hosting (such as GitHub Pages) can host the visual website, but it does not add the missing database or exam security. Free service quotas and simultaneous-user capacity are not guaranteed. Do not advertise a 10,000-participant capacity until the complete system has been load-tested.
